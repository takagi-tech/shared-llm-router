# アプリ経由の実機測定結果

実施日: 2026-09-18

すべて管理画面の「負荷試験」から開始し、アプリ自身の負荷生成・中継・計測・永続化を使った。ブラウザ操作の補助は試験を開始して保存済み結果を読むだけで、別の推論スクリプトからGPUへ負荷を送っていない。

対象は `dev-qwen` / `qwen-main` / `qwen3.8-27b`。Endpoint直接モードで測定し、試験中は対象Endpointの通常受付を保守状態とした。完了後に通常受付を再開し、運用Capacityは1を維持した。

各条件1要求。合成入力32,000／120,000単語、連続生成は最大16,384出力トークンで実行した。すべて試験に限って`ignore_eos=true`を指定。120,020トークンの入力では最初の生成まで310秒を超え、Router独自の300秒打切りがない通信経路を実機で確認した。16,384トークン生成は約86秒であり、数十分・数時間の連続生成を検証したものではない。
