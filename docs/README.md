## 文書の扱い

- 要件・決定記録はユーザーの方針、実装設計は現在の方式、実装・検証状況は確認した範囲を示します。実装済みと実機検証済みを区別します。
- 開発計画は初期工程の進捗と残作業を管理します。初期の要件IDと決定日を維持し、追加決定を追記します。
- 実機測定結果は当時のエンジン・モデル・Alias・条件を残す履歴です。最新の登録設定は管理画面を確認してください。
- 新規負荷試験の操作はGuideLLM運用を参照してください。旧エンジンの単語数指定は新規フォームへ適用しません。
